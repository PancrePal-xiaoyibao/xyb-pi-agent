# MDT 视角会诊准备

帮患者把**一个问题拆成多个专科视角**去准备，最后拿到一份能拿去和医生谈的清单。

> 名字上先说清楚：这里的每一个都是**软件角色**，没有看原片、没有看病理切片、不承担任何责任。
> 真实 MDT 是多位医生共同署名负责的。所以本技能一律用「**视角**」，不用「专家」，
> 也**不出会诊结论**——它替代不了 MDT，只是让你去谈的时候更有准备。

## 一、先齐料（缺了就问，不要猜）

派发视角之前必须拿到这些，缺哪项就单独问哪项：

| 类别 | 需要什么 |
|---|---|
| 基本情况 | 年龄、性别、确诊时间、目前体能（能自理到什么程度） |
| 诊断 | 病种、组织学类型（若已知）、临床分期、有无转移及部位 |
| 影像 | 最近一次 CT/MRI/PET-CT 的报告原文关键句；是否胰腺专用增强 CT |
| 病理 | 取材方式（穿刺细胞学 / 组织学 / 手术标本）、报告原文关键句、免疫组化 |
| 分子 | 做过哪些检测与结果（KRAS、MSI/MMR、BRCA 等）；没做过也要写明 |
| 治疗 | 用过什么方案、几周期、疗效、停用原因；现在在做什么 |
| 症状 | 黄疸、疼痛、进食、体重变化、排便、血糖 |
| 检验 | 胆红素、肝肾功能、血象、肿瘤标志物（有则给） |

**摘要里没有的，一律写「未提供」，不要根据经验补全。** 缺料是这个场景的常态，
不是缺陷——把缺什么说清楚，本身就是产出的一部分。

## 二、按问题选视角，不要每次全开

七个视角是**工具箱**，不是每次都要齐上。按患者真正的问题选 2–4 个：

- 问「能不能手术」→ 影像 + 外科（+ 肿瘤内科，若需先做新辅助）
- 问「下一步怎么治」→ 肿瘤内科 + 病理（看分子分型）+ 影像
- 问「黄疸/疼痛/吃不下的怎么办」→ 介入 + 营养
- 问「这份病理报告怎么看」→ 病理（单开就够）
- 整体拿不准、想要一次全景 → 外科 + 肿瘤内科 + 影像 + 病理（这是核心四科）

**全开七个只有在患者明确要求"从头到尾理一遍"时才做**，因为每个视角都是一次独立的模型调用。

## 三、并行派发，每个只给相关切片

- 把互不依赖的视角**并行**发出去，不要串行
- 每个视角的 brief 里**只放它需要的那部分资料**：
  病理视角不需要血糖，营养视角不需要血管包绕角度。这既减少无关信息干扰，
  也避免把整个病例无必要地铺开
- brief 里明确交代：资料来自患者自述与报告摘录，**未见原始影像与切片**，
  没提供的不要假定
- 要求各视角按各自定义里的输出格式回答

## 四、汇总：呈现分歧，而不是平均成一个结论

这是本技能最关键的一步，做错就变成危险的假权威。

**必须做：**

1. **逐个呈现**每个视角说了什么，标明是哪个视角
2. **单独列一段「各视角的分歧点」**——哪些地方不同专科的侧重或倾向不一样，
   以及**为什么不一样**（看的东西不同、目标不同、证据等级不同）
3. **产出一份「问医生的清单」**：把各视角提的问题合并、去重、按就诊顺序排列，
   标注每条该问哪个科室
4. 列清**还缺哪些资料**，以及补齐后哪些结论才站得住
5. 全程带上依据与不确定性（共识 / 有争议 / 数据缺失）

**绝对不做：**

- ❌ 不写「综合各位专家意见，建议……」这类等于会诊结论的话
- ❌ 不把七份意见平均成一句结论，不给倾向性排序
- ❌ 不写「专家们认为」「会诊意见」「我们建议」
- ❌ 不做吉凶判断，不预测生存期，不给用药建议，不判断能否手术

分歧恰恰是最有价值的部分——它告诉患者「这里医生之间可能也会不一样，你要让医生解释依据」。

## 五、输出结构

```
多学科视角准备（不是会诊）

一、这次用了哪几个视角，以及为什么选它们
二、各视角分别说了什么
    【影像视角】……
    【外科视角】……
三、各视角之间不一致的地方，以及可能的原因
四、建议问医生的问题清单（标科室、按就诊顺序）
五、还缺哪些资料
六、提醒
```

结尾固定一句：

> 以上是从不同专科角度整理的问题与准备清单，**不是会诊意见，也不能替代任何医生的判断**。
> 真实 MDT 由医生共同署名负责；这份材料的作用，是让你和医生谈的时候问得更准。

## 六、与其他技能的分工

- 「临床试验助手」管试验检索与匹配
- 「中国试验来源接入」管数据源怎么调
- 各专科助手（病历 / 影像 / 病理 / 基因解读 / 决策辅助 / 营养 / 心理 / 并发症）
  管**单个专科的问题怎么问**
- 本技能管**把多个专科视角组织成一次准备**，并按需调用子智能体
