智能助手

这里不是菜单，而是给助手看的技能清单。你直接用自己的话提问，助手会挑合适的技能来做。
所有助手都只做信息整理，不能替代医生诊断，也不构成用药建议。
看资料
病历助手
把病理、影像、化验、治疗史整理成一份结构化病情档案，缺失项会明确标出。
试试说：帮我理一下病情 / 按模板收集我的病情信息
影像助手
解读 CT / MRI / PET-CT 报告的字段与前后变化，讲清疗效评价是怎么算的。
试试说：这次复查结果怎么看 / 病灶有没有变化
病理助手
解读病理报告与免疫组化指标，按「重要提醒 / 针对性提示 / 简单科普」三段输出。
试试说：这份病理报告什么意思 / Ki-67 高不高
基因解读助手
解读基因与分子检测结果，按「是什么 → 临床意义 → 可讨论的方向」讲，并标注证据等级。
试试说：这个突变意味着什么 / MSI 和 TMB 怎么看
做判断
决策辅助助手
按 MDT 框架把候选方案摊成多维度对比表，产出「该和医生讨论什么」，不替你决定。
试试说：这两种方案帮我比较一下 / 按 MDT 思路理一下
临床试验助手
在 ClinicalTrials.gov 与中国登记平台检索、筛选、整理候选试验，附来源与更新时间。
试试说：帮我找胰腺癌正在招募的试验
顾生活
营养支持助手
营养风险评估、治疗期饮食安排、症状应对，并列明需要立即就医的信号。
试试说：没胃口怎么办 / 体重一直掉怎么吃
心理支持助手
情绪陪伴、家属照护压力、病情沟通方法，以及安宁疗护的基础知识。
试试说：不知道该怎么告诉家人 / 最近总睡不着
并发症助手
按红 / 黄 / 绿分级判断症状的紧急程度，给出就医时机。分级永远放在最前面。
试试说：化疗后一直发烧要不要去医院
助手技能都是纯 Markdown 文档，你可以直接读和改。
其中「临床试验助手」由「找试验」插件提供——它需要联网检索，所以权限单独管理。
心理支持出现危机信号时，助手会直接给出求助渠道，不会淡化处理。
