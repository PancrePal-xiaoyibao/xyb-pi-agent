# 小胰宝 · 我的资料（`xyb.records`）

把患者散落的检查报告、影像与就诊资料，归到一个**本地**资料库，并生成患者可读的病情摘要。

## 患者视角它解决什么

- 报告东一份西一份，想找上次的 CT 结果要翻半天
- 想给别人看病情，每次都要口头复述
- 想让 AI 帮忙看看，又担心隐私

## 能力

| 能力 | 形态 | 是否联网 |
|---|---|---|
| 导入资料并自动归类 | 命令 `xyb.records.import` + 视图按钮 | 否（纯本地扫描） |
| 生成患者友好病情摘要 | 技能 `skills/patient-summary.md`（由助手执行） | 仅在使用 AI 时，且先脱敏 |
| 资料库位置配置 | 插件设置 `vaultDir` | 否 |
| 发送前自动隐藏个人信息 | 插件设置 `redactBeforeAi`（默认开） | — |

## 权限说明

| 权限 | 用途 | 风险级 |
|---|---|---|
| `ui.view` | 在右侧工作面板显示「我的资料」 | 低 |
| `fs.read` / `fs.write` | 读取并整理用户选择的资料目录 | 中 / 高 |
| `agent.prompt.inject` | 让助手加载"病情摘要"技能 | 高 |
| `notify` | 导入完成的提示 | 低 |

`manifest.fs` 声明了 `read` / `write` 均为 `**/*`，实际作用域受用户选择目录约束（`pi.fs.requestDirectory`）。

## 开发

```bash
# 在仓库根目录校验
pnpm pi-plugin check apps/desktop/resources/plugins/xyb.records
```

启动应用后：**插件 → 加载开发插件** → 选择本目录。改动会自动热重载。

## 数据与隐私

- 资料只存在本地，不上传、不建账号
- 送出模型前，姓名/电话/身份证/医院名会替换为占位符
- 卸载插件不会删除用户资料
