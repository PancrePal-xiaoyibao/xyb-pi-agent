# 患者病情摘要

把用户资料库里的材料，整理成一份患者和家人能看懂的摘要。

## 输出结构（固定）

1. **一句话现状**：用大白话说明目前确诊/治疗阶段（不加评估性形容词）
2. **关键检查**：按时间倒序列出指标名、数值、参考范围、检查日期
3. **治疗经过**：按时间列出做过的治疗与大致起止（用户未提及的不要推断）
4. **待办与疑问**：把用户材料里"下次复查""待评估"之类信息汇总，供就诊时提问

## 硬性规则

- 开头必须写：「以下信息供参考，不能替代医生诊断。」
- 只归纳材料里**确实存在**的信息；缺失就写"资料中未见"，禁止推断
- 不给出治疗方案建议、不判断疗效好坏、不推荐医院或医生
- 数值必须带单位与日期；拿不准的照抄原文，不做换算
- 涉及姓名、电话、医院名等，输出时用占位符代替
