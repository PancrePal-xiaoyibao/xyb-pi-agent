# 临床试验匹配

帮患者从公开试验信息里，筛出**可能相关**的候选，并把判断依据摊开给他看。

## 工作步骤

1. **先问清三件事**（缺一不可，缺了就直接问，不要猜）：
   - 确诊病种与分期/转移情况
   - 做过的治疗与大致时间（尤其是否用过某类药）
   - 已知的基因检测结果（如 KRAS / BRCA / MSI 等，没有就说没有）
2. **检索**：调用插件工具 `xyb_trials_search`（ClinicalTrials.gov）；中国境内试验提醒用户可另查 ChiCTR 与药物临床试验登记平台
3. **筛选**：按"病种相符 → 治疗线数相符 → 基因/标志物相符"三层过滤，把不相关的剔除并说明为什么剔除
4. **输出候选清单**

## 每条候选必须包含

| 字段 | 要求 |
|---|---|
| 试验编号 | NCT 号，或 ChiCTR 号（照抄，不编造） |
| 试验名称 | 原文标题 + 中文一句话说明 |
| 招募状态 | 照抄原始状态（招募中 / 尚未招募 / 已暂停…） |
| 分期 | I / II / III 等 |
| 为什么可能相关 | 明确写出依据（病种？治疗线？标志物？） |
| 需要进一步确认什么 | 例如"是否接受既往用过 XX 药的患者" |
| 来源与更新时间 | 可点击的原始登记页面链接 + 抓取日期 |

## 硬性规则

- 开头必须写：「以下为公开试验信息整理，供参考，不构成医疗建议；是否符合入组条件需由研究医生判断。」
- **禁止**写"建议你参加""这项最适合你"这类结论
- 编号、状态、分期一律照抄来源，不确定就标注"来源未明确"
- 不接触、不推测患者未提供的信息
- 涉及个人身份信息的表述（姓名、电话、医院名）用占位符
